Mixin 执行顺序（MRO）

Python 会按 MRO 顺序查找 dispatch()。因此 LoginRequiredMixin 必须在最左边 才能优先命中它的 dispatch。

VipCBVView.mro()
    {% for c in vip_mro %}
  1. {{ c }}
    2. {% endfor %}
常见错误：把继承写成 class VipCBVView(TemplateView, LoginRequiredMixin)， 会导致 TemplateView 的 dispatch 先被解析，门禁失效。
