# 05 项目初始化与工程规范



## 一、基础环境

### 1.1 Python & Conda

**不接受 system python，不接受 venv**

```bash
conda create -n moviesstore python=3.11 -y
conda activate moviesstore
python --version
```



要求输出：

```
Python 3.11.x
```



### 1.2 后端依赖

```bash
pip install django==5.0.1
pip install djangorestframework==3.14.0
pip install mysqlclient==2.2.4
pip install python-dotenv==1.0.0
pip install redis==5.0.1
pip install django-cors-headers==4.3.1
pip install djangorestframework-simplejwt==5.3.1
```



## 二、创建 Django 工程

### 2.1 初始化项目

在**空目录**执行：

```bash
mkdir moviesstore
cd moviesstore
django-admin startproject config .
```

此时目录必须是：

```
.
├── config/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py
└── manage.py
```



## 三、创建 apps 工程结构

### 3.1 创建 apps 包

```powershell
mkdir apps
New-Item -ItemType File -Path "apps\__init__.py" -Force
```



### 3.2 创建业务域目录

```powershell
mkdir apps\movie_auth
mkdir apps\accounts
mkdir apps\content
mkdir apps\wallet
mkdir apps\payment
mkdir apps\orders
mkdir apps\membership
mkdir apps\download
```



### 3.3 生成 Django App

**注意路径参数**

```powershell
python manage.py startapp movie_auth apps/movie_auth
python manage.py startapp accounts apps/accounts
python manage.py startapp content apps/content
python manage.py startapp wallet apps/wallet
python manage.py startapp payment apps/payment
python manage.py startapp orders apps/orders
python manage.py startapp membership apps/membership
python manage.py startapp download apps/download
```



### 3.4 修正 AppConfig

逐个检查 `apps.py`，例如：

```python
# apps/content/apps.py
from django.apps import AppConfig

class ContentConfig(AppConfig):
    default_auto_field = "django.db.models.BigAutoField"
    name = "apps.content"
```

**所有 app 必须是 `apps.xxx`**

### 4.2 .env

项目根目录创建 `.env`：

```env
DEBUG=True
SECRET_KEY=django-insecure-change-this-key

DB_NAME=moviesstore
DB_USER=root
DB_PASSWORD=root
DB_HOST=127.0.0.1
DB_PORT=3306

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_DB=0
```



### 4.3 加载 .env

```python
from pathlib import Path
import os
from dotenv import load_dotenv

BASE_DIR = Path(__file__).resolve().parent.parent
load_dotenv(BASE_DIR / ".env")
```



### 4.4 MySQL 数据库

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.mysql",
        "NAME": os.getenv("DB_NAME"),
        "USER": os.getenv("DB_USER"),
        "PASSWORD": os.getenv("DB_PASSWORD"),
        "HOST": os.getenv("DB_HOST"),
        "PORT": os.getenv("DB_PORT"),
        "OPTIONS": {
            "charset": "utf8mb4",
            "init_command": "SET sql_mode='STRICT_TRANS_TABLES'",
        },
    }
}
```



### 4.5 Redis缓存限流

```python
REDIS_URL = f"redis://{os.getenv('REDIS_HOST')}:{os.getenv('REDIS_PORT')}/{os.getenv('REDIS_DB')}"
```

## 五、URL 结构

### 5.1 主路由

config/urls.py

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("api/", include("apps.content.urls")),
]
```



### 5.2 content 小接口

apps/content/views.py

```python
from django.http import JsonResponse

def health(request):
    return JsonResponse({"status": "ok"})
```



apps/content/urls.py

```python
from django.urls import path
from .views import health

app_name = "content"

urlpatterns = [
    path("health/", health),
]
```

```bash

```



## 七、启动并验证

```bash
python manage.py runserver
```

必须同时满足：

- http://127.0.0.1:8000/api/health/ 返回 `{"status": "ok"}`
- http://127.0.0.1:8000/admin/ 可登录
- MySQL 中已生成 Django 系统表



## 八、总结

完成本阶段，意味着：

- Django 工程结构**不会再调整**
- apps 拆分已经固定
- settings.py 是真实生产级写法
- 后续只做增量开发（ORM / Service / API）
