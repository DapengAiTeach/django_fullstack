# 电影商城需求分析文档

## 1. 项目概述

### 1.1 项目背景
本项目是一个基于Web的电影商城系统，提供数字电影资源的在线观看和下载服务。用户可以通过金币购买电影或开通VIP会员，享受不同的观影权益。

### 1.2 项目目标
- 为用户提供便捷的电影浏览、购买、观看和下载服务
- 建立完善的用户体系和会员制度
- 提供金币支付系统，简化交易流程
- 为管理员提供高效的后台管理功能

### 1.3 技术栈
- **后端框架**：Django
- **前端框架**：Bootstrap
- **图标库**：FontAwesome
- **数据库**：待定（建议使用PostgreSQL或MySQL）

## 2. 用户角色分析

### 2.1 普通用户
- 可以浏览所有电影信息
- 可以观看免费电影
- 可以购买付费电影（使用金币）
- 购买后可以播放和下载电影
- 可以开通VIP会员（使用金币）
- 可以发表评价和评论
- 可以查看个人订单和金币记录

### 2.2 VIP用户
- 继承普通用户的所有权限
- 可以观看所有电影（包括付费电影）
- 不能下载任何电影
- 可以发表评价和评论
- 可以查看个人订单和金币记录

### 2.3 管理员
- 用户管理（查看、编辑、删除用户）
- 电影管理（添加、编辑、删除电影）
- 金币管理（为用户代充金币）
- 订单管理（查看所有订单）
- 评论管理（审核、删除评论）
- 系统配置管理

## 4. 业务规则

### 4.1 电影访问规则
- **免费电影**：所有用户（包括未登录用户）都可以观看
- **付费电影**：
  - 普通用户：购买后可以观看和下载
  - VIP用户：可以直接观看，但不能下载
  - 未登录用户：只能查看详情，不能观看和下载

### 4.2 下载权限规则
- 只有购买过该电影的普通用户可以下载
- VIP用户不能下载任何电影
- 未登录用户不能下载

### 4.3 金币支付规则
- 所有消费（购买电影、开通VIP）都使用金币支付
- 购买前检查金币余额是否充足
- 金币不足时提示用户
- 支付成功后扣除相应金币并生成订单

### 4.4 VIP会员规则
- VIP会员可以观看所有电影（包括付费电影）
- VIP会员不能下载任何电影
- VIP会员有到期时间，到期后自动降级为普通用户
- VIP会员可以续费

### 4.5 用户权限规则
- 未登录用户只能浏览电影信息和观看免费电影
- 登录后可以进行购买、收藏、评价等操作
- 管理员拥有所有管理权限

## 6. 非功能需求

### 6.1 性能要求
- 页面加载时间不超过3秒
- 视频播放流畅，无卡顿
- 支持并发用户数：至少1000人同时在线
- 数据库查询优化，避免N+1查询

### 6.2 安全要求
- 用户密码使用加密存储（如bcrypt）
- 防止SQL注入
- 防止XSS攻击
- 防止CSRF攻击
- 文件上传安全验证
- 敏感操作需要二次验证（如修改密码）
- 登录失败次数限制，防止暴力破解

### 6.3 可用性要求
- 系统可用性达到99.5%
- 友好的用户界面
- 清晰的错误提示
- 响应式设计，支持PC端和移动端
- 操作流程简单直观

### 6.4 可维护性要求
- 代码结构清晰，遵循Django最佳实践
- 完善的注释文档
- 模块化设计，便于扩展
- 日志记录完善

### 6.5 可扩展性要求
- 支持添加新的电影分类
- 支持添加新的VIP套餐
- 支持添加新的支付方式（预留接口）
- 支持添加新的视频格式
