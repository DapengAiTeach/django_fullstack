# 电影商城项目主题设计方案

## 1. 设计理念

### 1.1 核心定位
- **项目类型**：视频点播/电影商城平台
- **目标用户**：电影爱好者，追求高品质观影体验
- **设计风格**：现代、专业、沉浸式、高品质

### 1.2 设计原则
- **沉浸式体验**：让用户专注于内容本身
- **视觉冲击力**：突出电影海报和视频内容
- **简洁高效**：减少视觉干扰，提升用户体验
- **响应式设计**：完美适配各种设备
- **品牌一致性**：统一的视觉语言

## 7. 响应式断点

```css
/* 移动设备 */
@media (max-width: 576px) {
  /* 小屏手机 */
}

/* 平板设备 */
@media (min-width: 576px) and (max-width: 768px) {
  /* 大屏手机/小平板 */
}

/* 中等屏幕 */
@media (min-width: 768px) and (max-width: 992px) {
  /* 平板 */
}

/* 大屏幕 */
@media (min-width: 992px) and (max-width: 1200px) {
  /* 小屏桌面 */
}

/* 超大屏幕 */
@media (min-width: 1200px) {
  /* 大屏桌面 */
}
```
