# 明暗主题切换功能设计方案

## 1. 设计理念

### 1.1 核心目标
- 提供用户友好的主题切换体验
- 保持主题切换的持久化存储
- 实现平滑的主题过渡效果
- 支持系统主题自动检测

### 1.2 设计原则
- **用户控制**：用户可以自由切换主题
- **状态持久**：刷新页面后保持主题选择
- **系统感知**：自动检测系统主题偏好
- **平滑过渡**：主题切换时有流畅的动画
- **无障碍支持**：确保对比度符合标准

## 2. 交互设计

### 2.1 切换按钮位置

#### 方案A：导航栏右上角（推荐）
```
┌─────────────────────────────────────────────┐
│  Logo  首页  电影        [🌙] [用户] │
```

- 在移动端可能需要调整位置

```
┌─────────────────────────────────────────────┐
```

**优点：**

## 3. 技术实现

### 3.1 主题状态管理

#### 存储方案：localStorage
```javascript
// 保存主题
function saveTheme(theme) {
    localStorage.setItem('theme', theme);
}

// 读取主题
function getTheme() {
    return localStorage.getItem('theme') || 'dark';
}

// 删除主题
function removeTheme() {
    localStorage.removeItem('theme');
}
```

#### 系统主题检测
```javascript
// 检测系统主题偏好
function getSystemTheme() {
    if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
        return 'dark';
    }
    return 'light';
}
```

### 3.2 主题切换逻辑

#### 初始化流程
```javascript
// 页面加载时
1. 检查localStorage中是否有主题偏好
2. 如果有，使用保存的主题
3. 如果没有，检测系统主题偏好
4. 应用主题到document.documentElement
5. 更新切换按钮图标
```

#### 切换流程
```javascript
// 用户点击切换按钮时
1. 获取当前主题
2. 切换到相反主题（dark ↔ light）
3. 保存新主题到localStorage
4. 应用主题到document.documentElement
5. 更新切换按钮图标
6. 触发主题切换事件
```

### 3.3 CSS实现

#### 主题变量定义
```css
/* 深色主题（默认） */
:root {
    --primary-dark: #0f1014;
    --secondary-dark: #1a1c23;
    --text-primary: #ffffff;
    --text-secondary: #b2bec3;
    /* ... */
}

/* 浅色主题 */
[data-theme="light"] {
    --primary-dark: #ffffff;
    --secondary-dark: #f8f9fa;
    --text-primary: #2d3436;
    --text-secondary: #636e72;
    /* ... */
}
```

#### 主题切换动画
```css
/* 平滑过渡 */
* {
    transition: background-color var(--transition-slow),
                color var(--transition-slow),
                border-color var(--transition-slow);
}

/* 主题切换时的淡入淡出效果 */
@keyframes themeFadeIn {
    from {
        opacity: 0;
    }
    to {
        opacity: 1;
    }
}

body.theme-switching {
    animation: themeFadeIn 0.5s ease-out;
}
```

## 6. 无障碍支持

### 6.1 对比度要求
- 深色主题：文本与背景对比度 ≥ 4.5:1
- 浅色主题：文本与背景对比度 ≥ 4.5:1
- 大文本：对比度 ≥ 3:1

### 6.2 键盘导航
- 切换按钮可通过Tab键访问
- 焦点状态清晰可见
- 支持Enter键切换主题

### 6.3 屏幕阅读器
- 添加aria-label属性
- 提供alt文本
- 通知主题切换事件

```html
<button class="theme-toggle" 
        aria-label="切换主题" 
        title="切换到浅色/深色主题">
    <i class="fas fa-sun"></i>
</button>
```
